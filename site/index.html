steamplg

Shows whether a game's current price is a new historical low or matches the historical low, right on Steam store pages inside the Steam desktop client.

在 Steam 客户端里浏览商店游戏页时，标题旁会直接显示 新史低 / 平史低 / 非史低。

How it works

The Steam client renders its store with an embedded Chromium (CEF). When Steam is started with -cef-enable-debugging, steamplg connects to that local debugging port, detects the game page you are viewing, looks up Steam's price history for your region via the IsThereAnyDeal API, and inserts a badge next to the title:

  • 新史低 new historical low — cheaper than ever before
  • 平史低 matches the historical low
  • 非史低 · 史低 24 not a historical low (with the lowest price shown)

Only Steam's own price history is compared, and only discounted entries in the same currency.

Code signing policy

Windows releases: free code signing provided by SignPath.io, certificate by SignPath Foundation. Windows binaries are built from this repository by GitHub Actions on GitHub-hosted runners, and every signing request is manually approved.

macOS releases are signed with the maintainer's Apple Developer ID and notarized by Apple.
